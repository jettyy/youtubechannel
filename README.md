# 유튜브 채널 → 텔레그램 자동 링크 전송기

유튜브 **채널 주소**를 등록하면, 그 채널의 영상 링크를 **최신 영상부터 차례대로**
내 컴퓨터에 열려 있는 **텔레그램 채팅창**에 정해진 시간 간격마다 자동으로 입력(전송)합니다.

- 채널의 마지막(가장 오래된) 영상까지 보내면 **다시 최신 영상부터 무한 반복**
- 한 바퀴를 돌 때마다 영상 목록을 새로 불러와서 **그사이 올라온 새 영상도 반영**
- **여러 채널 등록 가능**
  - `채널 번갈아`: A채널 1번 → B채널 1번 → A채널 2번 → B채널 2번 …
  - `한 채널씩 끝까지`: A채널 전체 → B채널 전체 → 다시 A채널 …
- 웹 대시보드에서 시작/정지, 간격 설정, 진행 상황, 전송 기록 확인
- 프로그램을 껐다 켜도 **진행 위치가 저장**되어 이어서 진행

## 준비물

1. **파이썬 3.10 이상** – https://www.python.org/downloads/
   (윈도우 설치 시 **“Add python.exe to PATH”** 체크 필수)
2. **텔레그램 데스크톱 앱** – 보낼 채팅방을 열어 둔 상태

## 실행 방법

### 윈도우
`run_windows.bat` 을 더블클릭하세요.
처음 한 번은 필요한 프로그램을 자동 설치하고, 브라우저에 대시보드(http://127.0.0.1:8765)가 열립니다.

### 맥
1. python.org 에서 macOS 용 파이썬(3.10 이상)을 설치합니다. (맥 기본 python3 는 버전이 낮을 수 있음)
2. **터미널** 앱을 열고 `bash ` (bash 뒤에 한 칸 띄우기)를 입력한 뒤,
   Finder 에서 `run_mac.command` 파일을 터미널 창으로 끌어다 놓고 엔터를 누릅니다.
   (파일을 더블클릭하면 “확인되지 않은 개발자” 경고로 막힐 수 있어서 이 방법을 권장)
3. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 **터미널**을 켜 주세요.
   이 권한이 있어야 텔레그램 창에 자동 입력이 됩니다. (권한을 준 뒤 터미널을 껐다 켜서 다시 실행)

### 직접 실행
```bash
pip install -r requirements.txt
python app.py
```

## 사용 순서

1. 텔레그램 데스크톱에서 링크를 보낼 **채팅방을 열어 둡니다.**
2. 대시보드 **채널 추가**에 유튜브 채널 주소를 입력합니다. (여러 개는 줄바꿈)
   - `https://www.youtube.com/@채널이름`
   - `https://www.youtube.com/channel/UC...`
   - `@채널이름` 만 입력해도 됩니다.
3. 채널 목록에서 상태가 **준비됨**이 되고 영상 개수가 표시되면 OK.
4. **설정**에서 전송 간격(초/분/시간)을 정하고 **설정 저장**.
5. **테스트 메시지 보내기**로 텔레그램 채팅창에 제대로 입력되는지 먼저 확인하세요.
6. **▶ 시작**을 누르면 설정한 대기 시간(기본 5초) 뒤부터 자동 전송됩니다.

## 설정 설명

| 항목 | 설명 |
|---|---|
| 전송 간격 | 링크 하나 보내고 다음 링크까지 기다리는 시간 |
| 랜덤 추가 대기 | 간격에 0~N초를 무작위로 더해 매번 조금씩 다르게 보냄 |
| 여러 채널 순서 | 채널 번갈아 / 한 채널씩 끝까지 |
| 보낼 영상 기간 | `전체 영상` 또는 `최근 N개월`(1~36개월). 유튜브의 "3주 전·8개월 전" 표시로 계산한 **대략적인 날짜** 기준입니다. 한 바퀴 돌 때마다 목록을 새로 불러오므로 기간이 지난 영상은 자동으로 빠지고 새 영상은 들어옵니다. 기간 안에 영상이 없는 채널은 건너뜁니다. |
| 텔레그램 창 제목 | 이 글자가 들어간 창을 찾아 맨 앞으로 가져온 뒤 입력 (기본 `Telegram`) |
| 메시지 입력칸 클릭 위치 | 설정하면 붙여넣기 전에 그 위치를 클릭해 입력칸에 커서를 둡니다. **위치 잡기**를 누르고 5초 안에 마우스를 텔레그램 입력칸 위에 올려 두세요. 창을 옮기면 다시 잡아야 합니다. |
| 보낼 문구 | 기본은 `{url}` (링크만). 예: `{channel} - {title}\n{url}` 처럼 제목/채널명도 가능 |
| Enter로 전송 | 붙여넣은 뒤 Enter 를 눌러 실제로 전송 |
| 쇼츠 / 라이브 포함 | 일반 영상 외에 쇼츠, 지난 라이브 영상도 목록에 포함 (일반 영상 다음 순서로 붙음) |
| 창 못 찾으면 보내지 않기 | 텔레그램 창을 못 찾으면 엉뚱한 곳에 입력하지 않고 건너뜀(다음 차례에 같은 영상 재시도) |
| 테스트 모드 | 실제로 입력하지 않고 기록에만 남김 (동작 확인용) |

채널 목록의 버튼:
- **새로고침**: 영상 목록 다시 불러오기
- **처음부터**: 해당 채널을 최신 영상부터 다시 시작
- **↑ ↓**: 채널 순서 변경 / 체크박스로 채널 켜고 끄기

## 주의사항

- 키보드·마우스를 자동으로 조작하는 방식이라 **컴퓨터가 켜져 있고, 화면 잠금/절전 상태가 아니어야** 합니다.
  (윈도우 전원 설정에서 “화면 끄기/절전 모드”를 “안 함”으로 두는 것을 권장)
- 전송하는 순간 텔레그램 창이 맨 앞으로 오고 클립보드가 잠깐 사용됩니다. 그 순간 다른 곳에 타이핑 중이면 섞일 수 있습니다.
  전송 후 원래 클립보드 내용은 복구됩니다.
- **긴급 정지**: 대시보드의 **■ 정지** 버튼. 또는 자동 입력 중에 마우스를 화면 **구석(모서리)** 끝까지 밀면 입력이 멈추고 자동 전송이 정지됩니다.
- 전송 실패 시(창 없음 등) 그 영상은 건너뛰지 않고 다음 차례에 다시 시도합니다.
- 유튜브 구조가 바뀌어 목록을 못 불러오면 `pip install -U yt-dlp` 로 업데이트하세요. (실행 스크립트는 매번 자동 업데이트)
- 너무 짧은 간격으로 계속 보내면 텔레그램에서 스팸으로 제한될 수 있으니 적당한 간격을 권장합니다.
- 설정·채널·진행 위치는 같은 폴더의 `data.json` 에 저장됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 대시보드 웹 서버 (http://127.0.0.1:8765) |
| `engine.py` | 채널/진행 상태 관리, 간격마다 다음 영상 전송, 무한 반복 |
| `youtube.py` | 채널 주소 → 영상 목록(최신순) 가져오기 (yt-dlp) |
| `sender.py` | 텔레그램 창 활성화 → 붙여넣기 → Enter |
| `templates/index.html` | 대시보드 화면 |
